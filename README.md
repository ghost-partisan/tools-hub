# Toolivo

Free SEO-focused tools, calculators, and utilities.

## Hosting

The public site is deployed to Firebase Hosting.

- Primary site: `https://toolivo.web.app`
- Firebase project: `toolivo-b8a36`
- Static site files live in `public/`

Cloudflare Workers configuration remains in the repository for legacy/staging use.

No database or application server is required for the initial site.
