How the domain checker works

This tool queries RDAP, the standardized registration-data system that replaced WHOIS as the definitive source for generic top-level-domain registration information. A domain that returns registration data appears registered; a successful “not found” response can indicate that no registration record was found.

Registration status can change quickly, and an RDAP result is not a purchase quote. Always confirm availability and price with a registrar before registering a domain.

Why check more than one domain extension?
